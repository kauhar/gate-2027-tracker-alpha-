# GATE 2027 Study Tracker

Static phone-friendly tracker for GATE CS and DA.

## Deploy on GitHub Pages (Android-friendly)
1. Upload `index.html`, `manifest.webmanifest`, `icon.svg`, and `service-worker.js` to the **root** of your repository.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select your main branch and `/ (root)`, then Save.
5. Wait for the Pages URL to appear. Open it in Chrome. Use **⋮ → Add to Home screen**.

The topic lists are an organized tracker based on the GATE 2027 official CS and DA syllabus headings. Review the official syllabus for the complete detailed scope: https://gate2027.iitm.ac.in/exam_papers_and_syllabus

Data is stored in local browser storage on the device and does not sync automatically.
